# VisionCraft v2.2: Embedded Webview Mode

**Implementation Date:** February 24, 2026
**Status:** ✅ COMPLETE AND TESTED

## Overview

VisionCraft v2.2 enables Claude Code (and other MCP clients) to interact with web applications **inside VS Code's embedded webview**, eliminating the need for external Playwright browsers.

## Architecture

### v2.1 (External Browser)
```
Claude Code → MCP Server → Playwright → External Chrome Browser
```
**Limitation:** Website opens in separate application window

### v2.2 (Embedded Webview) ✅
```
Claude Code
  ↓ STDIO
MCP Server (standalone process)
  ↓ HTTP (localhost)
HttpBridge (VS Code extension)
  ↓ Direct method calls
WebviewBridge
  ↓ postMessage API
VS Code Webview Panel (embedded in VS Code)
```
**Benefit:** Website opens INSIDE VS Code in a preview panel

## Key Components

### 1. HttpBridge (Extension)
**File:** `packages/extension/src/mcp/HttpBridge.ts`

**Purpose:** HTTP server that bridges external MCP server to embedded webview

**Key Features:**
- Runs on random localhost port (security)
- Routes: `/health`, `/tools/list`, `/tools/call`
- Automatically opens preview on first request
- Calls WebviewBridge methods directly
- Returns raw results (not MCP-formatted)

**Code:**
```typescript
case 'visioncraft_screenshot':
  result = await webviewBridge.captureScreenshot(
    (args.format as 'jpeg' | 'png') || 'jpeg',
    (args.quality as number) || 80
  );
  break;
```

### 2. WebviewClient (MCP Server)
**File:** `packages/mcp-server/src/webview-client.ts`

**Purpose:** HTTP client that communicates with HttpBridge

**Key Features:**
- Implements same interface as browser-client
- Maps method names to tool names
- Makes HTTP POST requests to bridge
- Returns raw results from bridge

**Code:**
```typescript
async callBridge(method: string, ...args: any[]): Promise<any> {
  const response = await fetch(`${this.bridgeUrl}/tools/call`, {
    method: 'POST',
    body: JSON.stringify({
      method: 'tools/call',
      params: {
        name: this.mapMethodToTool(method),
        arguments: this.mapArgsToToolArgs(method, args),
      },
    }),
  });

  const data = await response.json();
  return data.result; // Raw result, not MCP format
}
```

### 3. Mode Selection (MCP Server)
**File:** `packages/mcp-server/src/index.ts`

**Logic:**
```typescript
// Check env var on startup
this.isWebviewMode = process.env.VISIONCRAFT_WEBVIEW_ENABLED === 'true';

if (this.isWebviewMode) {
  const bridgeUrl = process.env.VISIONCRAFT_BRIDGE_URL;
  this.webviewClient = new WebviewClient(bridgeUrl);
}

// Choose client based on mode
private getClient(url?: string) {
  if (this.isWebviewMode && this.webviewClient) {
    return this.webviewClient; // v2.2
  }
  return getBrowserClient(url); // v2.1 fallback
}
```

## Configuration

### .mcp.json
```json
{
  "mcpServers": {
    "visioncraft": {
      "command": "node",
      "args": ["packages/mcp-server/dist/index.js"],
      "env": {
        "VISIONCRAFT_WEBVIEW_ENABLED": "true",
        "VISIONCRAFT_BRIDGE_URL": "http://localhost:53535",
        "VISIONCRAFT_URL": "http://localhost:5175"
      }
    }
  }
}
```

**Environment Variables:**
- `VISIONCRAFT_WEBVIEW_ENABLED`: `"true"` for v2.2, omit for v2.1
- `VISIONCRAFT_BRIDGE_URL`: HttpBridge endpoint (from extension output)
- `VISIONCRAFT_URL`: Dev server URL (fallback)

### Extension Activation
**File:** `packages/extension/package.json`

```json
"activationEvents": [
  "onStartupFinished",  // Auto-activate on VS Code startup
  "onCommand:visioncraft.openPreview",
  "onCommand:visioncraft.testScreenshot",
  "onCommand:visioncraft.runV2Tests"
]
```

**Critical:** `onStartupFinished` ensures HttpBridge starts **before** Claude Code launches.

## Port Management

**Challenge:** HttpBridge uses random port on each VS Code restart.

**Solution:** Check extension output after reload:
```
View → Output → Select "VisionCraft"
Look for: ✨ HTTP Bridge started on port [NUMBER]
```

Update `.mcp.json` with new port and restart Claude Code.

## Key Fixes During Implementation

### Issue 1: Extension Not Activating
**Symptom:** VisionCraft output channel not appearing
**Cause:** Missing `onStartupFinished` activation event
**Fix:** Added to `activationEvents` in package.json

### Issue 2: playwright-core Missing
**Symptom:** `Error: Cannot find module 'playwright-core'`
**Cause:** CDPBridge imported but not used, requiring playwright-core
**Fix:** Removed CDPBridge import (not needed for v2.2)

### Issue 3: HttpBridge Port Mismatch
**Symptom:** `fetch failed` when calling tools
**Cause:** .mcp.json had old port from previous session
**Fix:** Update .mcp.json after each VS Code reload

### Issue 4: MCP Response Format Error
**Symptom:** `Expected string data URL, got object`
**Cause:** HttpBridge was calling EmbeddedMCPServer.handleToolCall() which returns MCP format
**Fix:** HttpBridge now calls WebviewBridge methods directly, returns raw results

### Issue 5: WebviewClient Parsing Error
**Symptom:** `a.match is not a function`
**Cause:** WebviewClient.extractResult() expected MCP format
**Fix:** Return `data.result` directly without extraction

## Benefits

1. **Better UX:** Web app visible alongside code in VS Code
2. **No External Dependencies:** No Playwright browser installation needed
3. **Cleaner Workflow:** Single window, no app switching
4. **Faster:** No browser launch overhead
5. **Secure:** HTTP bridge only on localhost

## Limitations

1. **Port Management:** Manual update needed after VS Code reload
2. **Single Instance:** One webview panel at a time
3. **Localhost Only:** HttpBridge not exposed externally

## Future Improvements

2. Support multiple webview panels

## Installation

### Build Extension
```bash
npx pnpm --filter visioncraft-extension build
```

### Package Extension
```bash
cd packages/extension
npx @vscode/vsce package --no-dependencies --baseContentUrl https://github.com/placeholder/vscode-eye/raw/main/packages/extension
```

### Install in VS Code
1. Cmd+Shift+P → "Extensions: Install from VSIX..."
2. Select `visioncraft-extension-1.0.0.vsix`
3. Click "Reload Now"

### Configure MCP
1. Check HttpBridge port: View → Output → "VisionCraft"
2. Update `.mcp.json` with port
3. Restart Claude Code

