## 🆘 Getting Help

### Before Asking for Help

1. **Check [Troubleshooting](TROUBLESHOOTING.md)** - Most issues are covered
2. **Run the diagnostic checklist** - [Quick Diagnostics](TROUBLESHOOTING.md#quick-diagnostics-checklist)
3. **Try the examples** - [Examples README](../examples/README.md)

### Reporting Issues

When reporting issues on GitHub, please include:

1. **Environment info:**
   - OS and version
   - Node version (`node --version`)
   - VS Code version (if using extension)

2. **Configuration:**
   - Your `vite.config.ts` (or webpack/babel config)
   - Claude Desktop config (for MCP)

3. **Error messages:**
   - Full error text
   - Console logs
   - Stack traces

4. **Steps to reproduce:**
   - What you were doing
   - What you expected
   - What actually happened

See [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed guidelines.
