# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating in this project, you agree to abide by its terms.

## Reporting

If you experience or witness unacceptable behavior, please report it by opening a [GitHub issue](https://github.com/SPra03/ai-eye/issues) or contacting the maintainers directly.

Reports will be reviewed promptly and handled confidentially.
